# QuarkDrive v0.1.3 — 视觉重构说明

本版本基于用户选择的 9 宫格 fnOS QuarkDrive 视觉原型进行重构。定位是**功能型 UI 版本升级**，不是夸克第三方接口和 fnOS 兼容性的正式认证版。

## 已实现（基于既有 API）

- **我的网盘**：紧凑侧边栏、层级导航、分页、搜索、批量选择、后端目录递归下载、文件类型图标和修改时间（有远端时间戳才展示）。
- **分享下载**：分享链接和提取码、分享预览、目录层级、批量勾选、NAS 下载确认。
- **下载任务**：五种任务筛选、实时数据定时刷新、下载进度（原生 progress）、速度、任务操作、详情弹窗、分片完成情况。
- **账号**：二维码登录对话框、扫码状态、账号资料弹窗、退出登录。
- **应用设置**：分组导航、并发、单文件连接数、分片大小、限速、磁盘预留、重试、临时文件清理和授权目录选择。
- **界面主题**：与 v0.1.2 的主题偏好兼容，浅色/深色/跟随 fnOS；修复后端未托管 `/assets/theme.js` 的缺陷。
- **交互**：回车搜索、文件选择、目录导航、下载确认、任务详情和暂停恢复重试等交互保留原 API，不引入模拟下载结果。

## 与参考图的差异与已知限制

- 视觉参考中的“首页账号总容量”“文件移动、删除、上传”“批量暂停/全部开始”等，在 v0.1.2 后端中没有相应 API，**未添加假的可点按钮**。
- 文件修改时间只有夸克列表接口提供 `updated_at` / `created_at` 时显示；否则是 `—`。
- 下载目录选择列举 `storage/locations` 已授权目录。更换后会保存为新的**全局默认下载目录**，因为目前后端不支持独立任务目标目录；下载历史中的原任务路径不会被改动。
- 当前任务进度继续使用 2.5 秒轮询，非 WebSocket；任务删除、批量操作和真正的 fnOS 原生文件夹选择器仍属于待开发需求。
- 浏览器验收使用测试脚本注入的 **mock HTTP API 数据**，不是已连通的夸克真实账号。未对真实 fnOS、Quark API、二维码或官方 fnpack 安装进行过认证。

## 验证

```bash
cd backend && go test -race ./... && go vet ./...
node --test tests/theme.test.cjs
node --check frontend/assets/app.js
python tests/ui_smoke.py --screenshots  # Python Playwright + Chromium
bash scripts/package-fpk.sh
```

UI 浏览器自动化 smoke 测试会在 `dist/ui-preview/` 生成实际渲染截图，测试账户、文件和任务仅存在于测试页面的网络 mock 中。后端及发布包不会携带这些假数据。

## 产物说明

在无官方 `fnpack` 的构建环境中，打包脚本只会生成标记 `UNVERIFIED` 的 FPK 候选包。请备份现有应用后仅在测试环境使用；安装、升级、启停、Cookie 登录等流程必须经过真实 fnOS 和夸克账号验收才能发布稳定版。
